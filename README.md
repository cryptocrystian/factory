# factory

Saipien Labs' agentic software factory — the studio's billable delivery engine. Deterministic control
plane (adapted from `sssf`) driving coding agents (Oh My Pi, constrained) through bounded, gated phases.
**Agent proposes, code disposes.**

Start at [MANIFEST.md](MANIFEST.md). Invariants (the hardstops) in [canon/invariants.md](canon/invariants.md).
The reasoning behind the system is in [design/](design/).

Status: standing up the kernel. First project: **Arxus** (`~/projects/arxus`), at P0.
